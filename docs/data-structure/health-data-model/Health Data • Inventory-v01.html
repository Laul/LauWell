Health Hub Data Inventory

Everything a personal health hub could plausibly hold, tagged along three axes that cut across medical topic. Sort or filter by an axis to see groupings that a topic-based menu would hide.

Shape
What the thing actually is. Stream = continuous series, Event = timestamped entry, Document = a file, Reference = a fact that rarely changes, Insight = computed from the rest.
Capture
How it gets in. Sensor costs the user nothing; Manual costs attention every single time and is where an app lives or dies; Import is bulk; Computed is free.
Looked at
How often it's consulted — not how often it's written. Emergency items must be reachable in seconds; Archival ones only need to be findable, never surfaced.
